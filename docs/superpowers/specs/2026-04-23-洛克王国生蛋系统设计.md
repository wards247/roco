# 洛克王国：世界 - 生蛋系统设计

## 概述

开发一个 Web 应用，用于管理洛克王国：世界中的精灵生蛋系统。

## 技术栈

- **前端框架**: React + TypeScript (Vite)
- **数据存储**: JSON 文件 (`data/egg-groups.json`, `data/my-pokemon.json`)
- **UI 风格**: 参考 https://roco.gptvip.chat/egg-group-query，简洁现代的游戏工具风格

## 数据结构

### 蛋组数据 (egg-groups.json)

```typescript
interface EggGroup {
  group_id: number;
  group_display: string;
  description: string;
  member_count: number;
  hatchable_member_count: number;
}

interface Pokemon {
  base_id: number;
  display_name: string;
  page_name: string;
  avatar_url: string;
  body_url: string;
  class_name: string;
  type_name: string;
  hatch_status_text: string;
  family_chain: string;
  family_key: string;
  member_count: number;
  can_hatch_member_count: number;
}
```

### 我的精灵数据 (my-pokemon.json)

```typescript
interface MyPokemon {
  base_id: number;
  egg_group_id: number;
  gender: 'male' | 'female' | 'unknown';
  is_mine: boolean;
}
```

## 核心功能

### 1. 精灵库浏览
- 按蛋组分类展示所有精灵
- 显示精灵头像、名称、类型、孵化状态
- 支持搜索精灵

### 2. 我的精灵管理
- 标记"我的精灵"
- 设置性别（雄性/雌性/未知）
- 数据持久化到 my-pokemon.json

### 3. 生蛋推荐
- 计算兼容性：同蛋组内，雄性 + 雌性 = 可生蛋
- 排名展示：按兼容性数量降序排列
- 显示格式："雌性A 和 6 个雄性兼容"

## 页面结构

### 导航栏
- Logo + 标题
- 菜单：精灵库 | 我的精灵 | 生蛋推荐

### 精灵库页面
- 蛋组选择器（下拉菜单）
- 精灵卡片网格（响应式布局）
- 每个卡片显示：头像、名称、类型、孵化状态

### 我的精灵页面
- 我的精灵列表（可筛选蛋组/性别）
- 编辑功能：修改性别、取消标记

### 生蛋推荐页面
- 统计：雄性数量、雌性数量
- 兼容性列表：按匹配数降序排列
- 显示每个雌性与哪些雄性兼容

## 组件设计

1. **Header** - 导航栏
2. **EggGroupSelector** - 蛋组选择器
3. **PokemonCard** - 精灵卡片
4. **PokemonGrid** - 精灵网格
5. **GenderToggle** - 性别切换
6. **BreedingRecommendation** - 生蛋推荐列表
7. **CompatibilityList** - 兼容性列表

## 数据流

1. 蛋组数据从 JSON 文件加载，缓存到 state
2. 我的精灵数据从 my-pokemon.json 加载
3. 用户修改后立即保存到 my-pokemon.json
4. 生蛋推荐实时计算
